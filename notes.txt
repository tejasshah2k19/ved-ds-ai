What is Data Frame? 
Data Frame : two dimensional labeled data structure that stores row and columns 

similiar to -> excel , sql database table , html table 

example 

Student Database 

index   Name    Age     Course 
0       Ram     25      C
1       Shyam   26      C++
2       Rock    31      Java 


rows represent individuai student records. 
columns represent students attributes. 
index - label 


difference between Series and DataFrame 

Series                          DataFrame 
1D Data                         2D Data 
single column data              multiple columns 
one index axis                  row and columns axis 
pd.Series()                     pd.DataFrame()
